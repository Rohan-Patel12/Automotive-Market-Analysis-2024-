# Automotive Market Analysis

Data analysis of 1,000+ vehicles from Kaggle dataset.

## Usage

Open `automotive_analytics.ipynb` in Jupyter Notebook to see the analysis.

## Dataset

Download from: https://www.kaggle.com/datasets/kanchana1990/vehicle-dataset-2024

## Results

- Analyzed 1,002 vehicles
- Identified pricing trends and market segments
- Created visualizations and insights
